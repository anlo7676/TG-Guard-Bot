## 仍需区分的运行边界

- 本地规则为文本特征匹配，不含图片 OCR，也不能保证覆盖所有广告变种。
- 单条直接动作按固定规则执行；累计升级仅作用于累计策略的违规决定。
- Telegram API 与本地数据库之间没有分布式事务，发送成功后进程在记录状态前崩溃，仍存在通知重复的窗口；已完成的处罚重试会跳过。
- 新机器人必须在群内获得管理权限并重新审批才能启用管理。保留配置不等于继承旧机器人授权。
