## 当前上线前依赖与范围

- 大模型 API 仍需部署者提供 Base URL、模型 ID 和 API Key。代码路径已通过模拟接口测试；没有凭据时不能宣称真实 AI 服务已连通或具备真实广告识别准确率。
- 自动审核先使用群配置的本地规则；AI 未启用时不会执行 AI 驱动处罚。
- 本地服务默认回环地址，手机访问及生产公网 Webhook 需要域名、HTTPS 反向代理和对应后台地址。当前没有发布公网服务。
- Windows 本机没有兼容 C 工具链，未运行 race；CI 配置可在 Linux 运行 race。没有执行真实群成员删除、禁言、封禁测试，也没有生产规模压测。
- 文档明确的后续功能（图片／Web CAPTCHA、OCR／二维码、语义相似 Spam、多租户订阅支付、独立多管理员 Web 账号、完整繁体／英文界面）仍不属于本次已实现能力。不要将此版本描述为上述所有商业化功能均已完成。

## 操作步骤

1. 本机更新与运行：`pwsh -File scripts/start-local.ps1`。
2. 登录后台：`pwsh -File scripts/open-panel.ps1`。
3. 机器人私聊发送 `/version` 检查版本，发送 `/menu` 取得新菜单。
4. 在目标超级群发送 `/settings@anlotest_bot`，点击“打开本群设置”；群主／群管理员可直接管理该群，无需先配置机器人全局管理员。
5. 在后台「群管理」点击“检查权限”，确认机器人拥有删除和限制成员权限。
6. 在「AI 接口」保存真实模型配置并测试连接，再开启目标群的 AI 审核。
7. 查看「验证记录」「审核记录」「处罚记录」「操作审计」。运行诊断中的失败任务先排除原因再手动重试；已经发送的通知可能再次发送。

数据升级通过 003_keyword_buttons.sql 添加可空 JSON 列，既有关键词和系统配置保留。数据库备份需要同时保存 `.env` 中的系统加密密钥。

补充审查：Base58 钱包地址先按原始大小写识别，再进入文本归一化，避免 Tron 地址转换小写后漏检；已有回归测试。真实群权限查询返回 bot_present、administrator、can_delete、can_restrict、ready 均为 true。失败任务重排也通过“首次成功、重复请求返回 404”的验收测试。
