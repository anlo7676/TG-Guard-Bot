# 流程审查记录（2026-09-06，v1.6.2）

## 检查范围

检查群授权与权限、私聊输入与关键词向导、入群验证与恢复、欢迎语清理，以及后台审批、关键词、名单、误判反馈和任务重试入口。结合现有验收测试复核本地广告动作、重复处罚保护和群配置隔离。

## 已修复

- 关闭验证时，同一配置事务将待验证、完成处理中、超时处理中的记录转为释放状态。工作任务恢复其验证禁言并持久化结果，失败沿用重试机制；执行前也检查当前验证开关。
- 被取消或正在释放的验证不再提示答案错误。Redis 连接或上下文故障不再被误报为验证提示过期。
- 私聊设置在权限查询、数据库读取或格式校验失败后恢复提示的剩余有效期，允许继续回复；明确取消、撤销权限和已完成的输入不恢复。
- 私聊关键词分步编辑和状态切换从数据库锁定读取最新记录，仅修改对应字段，避免覆盖同时修改的启用状态、优先级等。目标已删除时明确要求重新打开菜单。
- 后台误判反馈、关键词删除、名单移除、失败任务重试不再依赖原生 prompt/confirm，改为页面内确认。取消不写入，失败保留表单和原因，等待响应时阻止重复提交。

## 实际边界

- 群内验证链接作为公开按钮可被任何成员打开；服务端根据 Telegram 用户 ID 限制本人完成验证。
- 欢迎语第 295 秒进入删除队列、每秒扫描。Telegram 网络或权限故障会延迟删除，不能保证外部接口故障期间仍在 5 分钟内完成。
- Telegram 操作与本地数据库无法组成一个事务。进程恰好在远端成功、本地落库之前退出仍有重复通知窗口；本轮故障重试修复不等于所有外部操作严格只执行一次。
- 整页配置的显式保存仍以提交内容为准；本次并发保留修复针对私聊局部编辑，不应将旧后台页面视为自动合并器。
